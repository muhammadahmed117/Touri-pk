# 🌍 Touri PK

Touri PK is a tourism-based mobile application developed using Flutter that helps users explore popular destinations across Pakistan. The app provides location details, navigation assistance, and a user-friendly interface for discovering travel spots.

---

## 🚀 Features

* 📍 Explore popular tourist destinations in Pakistan
* 🗺️ Location-based navigation and map integration
* 📱 Clean and user-friendly interface
* ⚡ Fast and responsive performance
* 🏞️ Detailed information about travel locations
* 🔎 Easy browsing and search functionality

---

## ⚙️ Installation & Setup

### 1. Clone Repository

git clone https://github.com/muhammadahmed117/Touri-pk.git
cd Touri-pk

### 2. Install Dependencies

flutter pub get

### 3. Run Application

flutter run
